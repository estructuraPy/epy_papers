# Introducción

Las torres altas y esbeltas están gobernadas por el viento y no por la
gravedad. La presión dinámica que el viento ejerce sobre la fachada
escala con el cuadrado de su velocidad,

$$ q = \tfrac{1}{2}\,\rho\,V^{2} $$

por lo que las ráfagas, y no el peso propio, dimensionan el sistema
lateral.

| Propiedad    | Valor     |

| Altura       | 443 m     |
| Pisos        | 102       |
| Estructura   | 57 000 t  |

# Arriostramiento

El nivel de outrigger conecta el núcleo con las columnas de fachada y
limita la deriva en el estado límite de servicio.

# Conclusión

El viento gobierna el diseño lateral de esta torre; el sistema de
arriostramiento se deriva de esa demanda.
